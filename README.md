# 16:9白余白ツール

縦長の画像の左右に白い余白をつけて、16:9の画像にするブラウザツールです。

## 使い方

1. `index.html` をブラウザで開く（GitHub Pagesで公開した場合はそのURLを開く）
2. 画像をドラッグ＆ドロップするか、「ファイルを選択」で選ぶ（複数枚OK、jpg / png / webp）
3. 出力形式（JPG / PNG）を選ぶ
4. 出力サイズを選ぶ（初期値は横幅640px＝640×360。横幅は16〜8000pxで変更可。「リサイズしない」も選べる）
5. 1枚ずつ「ダウンロード」か、「すべてZIPでダウンロード」で保存する

## 加工ルール

- まず、高さは元画像と同じ、幅は `高さ × 16 / 9`（四捨五入）の白い背景の中央に元画像を置く
- 出力サイズ指定（初期値 640×360）: 横幅を指定すると、その横幅×`横幅 × 9 / 16`（四捨五入）に縮小して出力する（縮小は半分ずつ段階的に行い画質を保つ。元の16:9より大きい幅を指定すると拡大になり、カードに「拡大」と表示）
- 「リサイズしない」を選ぶと、元の高さのまま（縮小なし）で出力する
- 元画像がすでに16:9以上の横長なら加工しない
- ファイル名は、横幅指定時は `元のファイル名_640x360.jpg`（サイズは指定値、または `.png`）、リサイズしない場合は `元のファイル名_16x9.jpg`（または `.png`）

例: 216×362 → 644×362（左右の余白 214px）

## 補足

- 画像はブラウザの中で加工するだけで、外部には送信しません
- ZIPの作成に JSZip 3.10.1（cdnjs）を読み込んでいます
