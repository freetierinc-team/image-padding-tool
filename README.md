# 16:9白余白ツール

縦長の画像の左右に白い余白をつけて、16:9の画像にするブラウザツールです。

## 使い方

1. `index.html` をブラウザで開く（GitHub Pagesで公開した場合はそのURLを開く）
2. 画像をドラッグ＆ドロップするか、「ファイルを選択」で選ぶ（複数枚OK、jpg / png / webp）
3. 出力形式（JPG / PNG）を選ぶ
4. 1枚ずつ「ダウンロード」か、「すべてZIPでダウンロード」で保存する

## 加工ルール

- 出力の高さは元画像と同じ、幅は `高さ × 16 / 9`（四捨五入）
- 白い背景の中央に元画像を置く（拡大・縮小なし）
- 元画像がすでに16:9以上の横長なら加工しない
- ファイル名は `元のファイル名_16x9.jpg`（または `.png`）

例: 216×362 → 644×362（左右の余白 214px）

## 補足

- 画像はブラウザの中で加工するだけで、外部には送信しません
- ZIPの作成に JSZip 3.10.1（cdnjs）を読み込んでいます
